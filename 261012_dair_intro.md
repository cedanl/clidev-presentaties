# Van code naar prompt naar skill

<p class="np-subtitle">Elke stap maakt het bouwen sneller. De skill maakt het ook herhaalbaar.</p>

<div class="np-grid-3" style="margin-top: 0.6rem;">
  <div class="np-card accent-blue">
    <span class="np-badge blue">Eerst: code</span>
    <p class="muted" style="font-size: 0.84rem; margin: 0.4rem 0 0;">Alles zelf schrijven. Elke regel kost tijd.</p>
  </div>
  <div class="np-card accent-orange">
    <span class="np-badge orange">Toen: prompt</span>
    <p class="muted" style="font-size: 0.84rem; margin: 0.4rem 0 0;">De agent schrijft de code. Snel, maar elke keer anders.</p>
  </div>
  <div class="np-card accent-green">
    <span class="np-badge green">Nu: skill</span>
    <p class="muted" style="font-size: 0.84rem; margin: 0.4rem 0 0;">Een vast stappenplan met checks. Sneller en beter.</p>
  </div>
